= Games

Games listed below declared explicitly no usage of any AI assets. Usage of genAI in coding
is separated category, and is unknown (❔ emoji) by default unless stated
explicitly.

Games that confirm usage of AI code will either be removed or get separate
category - I haven't decided on this just yet.

The list is split into two sections - more important, link:games.adoc#_released[listing already released games],
and one for link:games.adoc#_indev[upcoming projects]. The second one was added
so that this file works also as a promotion tool - dunno about you, but I love
following gamedevs and see them posting showcases of new features from time
to time.
